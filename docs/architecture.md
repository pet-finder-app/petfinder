# Architecture

## Technologies

- Go 1.25 and `net/http`
- PostgreSQL and `pgx`
- SQLC for typed database access
- golang-migrate for schema versioning
- Docker Compose for the local environment
- OpenAPI 3.1 generated with Huma for the HTTP contract

## Layout

```text
cmd/api/             API composition and startup
cmd/openapi/         export of the generated OpenAPI contract
db/migrations/       PostgreSQL schema evolution
db/queries/          queries processed by SQLC
build/openapi.yaml   generated artifact, never edited by hand
e2e/                 end-to-end tests (build tag e2e)
internal/api/        HTTP handlers, validation and middleware
internal/auth/       passwords, tokens and authentication
internal/config/     configuration loading
internal/database/   code generated by SQLC
internal/domain/     domain types and state transitions
internal/email/      SMTP delivery
internal/moderation/ message moderation rules
```

Before pushing, run `make check`. Tests that need PostgreSQL must use an isolated database, never the local volume holding important data.
